# Αντίγραφα ασφαλείας της βάσης

Η παραγωγική βάση φιλοξενείται στη **Neon, δωρεάν πακέτο**, που δίνει:

| | Free plan |
|---|---|
| Στιγμιαία επαναφορά (history window) | **6 ώρες** |
| Χειροκίνητα snapshots | 1 |
| Branches | 10 |
| Προγραμματισμένα αντίγραφα | — |

Δηλαδή ένα λάθος που θα εντοπιστεί την επόμενη μέρα **δεν επαναφέρεται**, και
τίποτα από τα παραπάνω δεν επιβιώνει αν χαθεί ο λογαριασμός. Γι' αυτό υπάρχουν
αυτά τα scripts.

> **Το «Λήψη Πλήρους Backup» μέσα στην εφαρμογή δεν είναι αντίγραφο ασφαλείας.**
> Είναι εξαγωγή δεδομένων ενός πελάτη σε Excel, χωρίς σχήμα και χωρίς διαδρομή
> επαναφοράς. Χρήσιμο για τον πελάτη, άχρηστο σε καταστροφή.

## Ρύθμιση, μία φορά

```powershell
cd C:\Users\patsg\source\repos\RentApp\tools\backup
.\init-secrets.ps1      # connection string της Neon + κωδικός κρυπτογράφησης
.\backup-db.ps1         # δοκιμαστική εκτέλεση
.\install-task.ps1      # καθημερινά στις 03:00
```

Το `init-secrets.ps1` δοκιμάζει τη σύνδεση πριν αποθηκεύσει οτιδήποτε και
φυλάσσει τις τιμές στο `%LOCALAPPDATA%\RentApp\backup\`, κρυπτογραφημένες με
DPAPI — ανοίγουν μόνο από τον ίδιο λογαριασμό Windows στο ίδιο μηχάνημα.

> ⚠️ **Φύλαξε τον κωδικό κρυπτογράφησης και εκτός υπολογιστή.** Αν χαθεί ο
> υπολογιστής, το αρχείο DPAPI χάνεται μαζί του και **κανένα αντίγραφο δεν
> ανοίγει**. Βάλ' τον σε διαχειριστή κωδικών ή σε χαρτί.

Για να αλλάξεις διαδρομές, αντίγραψε τις γραμμές που θέλεις από το `settings.ps1`
σε ένα νέο `settings.local.ps1` (αγνοείται από το git).

## Τι κάνει το καθημερινό αντίγραφο

1. `pg_dump` σε custom μορφή, χωρίς ιδιοκτήτες και δικαιώματα (οι ρόλοι της Neon
   δεν υπάρχουν αλλού).
2. Κρυπτογράφηση AES-256 με κλειδί από τον κωδικό (PBKDF2, 200.000 επαναλήψεις)
   και HMAC-SHA256 για ακεραιότητα.
3. **Επαλήθευση στην ίδια εκτέλεση**: το αρχείο αποκρυπτογραφείται και διαβάζεται
   με `pg_restore --list`. Αν δεν περάσει, διαγράφεται και η εργασία αποτυγχάνει.
4. Αντιγραφή στον φάκελο OneDrive, ώστε να υπάρχει αντίγραφο εκτός μηχανήματος.
5. Καθαρισμός κατά GFS: **7 ημερήσια, 4 εβδομαδιαία, 6 μηνιαία** (κρατιέται το
   νεότερο κάθε εβδομάδας και κάθε μήνα· τα σύνολα επικαλύπτονται, οπότε τα
   αρχεία είναι συνήθως λιγότερα από 17).
6. Γραμμή στο `backup.log` και χρονοσήμανση στο `last-success.txt`.

Όνομα αρχείου: `rentapp-YYYYMMDD-HHmm.dump.enc`.

### Έλεγχος ότι δουλεύει

```powershell
Get-Content "$env:USERPROFILE\RentApp-Backups\last-success.txt"
Get-ScheduledTaskInfo -TaskName 'RentApp - Αντίγραφο βάσης'   # LastTaskResult = 0
```

### Μία φορά τον μήνα: άσκηση επαναφοράς

```powershell
.\verify-backup.ps1
```

Επαναφέρει το τελευταίο αντίγραφο σε προσωρινή τοπική βάση, μετράει τις γραμμές
και τη διαγράφει. **Ένα αντίγραφο που δεν δοκιμάστηκε δεν είναι αντίγραφο.**
Κωδικός εξόδου 0 = όλα καλά, 2 = επαναφέρθηκε αλλά λείπουν δεδομένα, 1 = αποτυχία.

## Runbook: τι κάνω όταν χαλάσει κάτι

### 1. Λάθος χειρισμός πριν από λίγες ώρες (διαγραφή, μαζική αλλαγή)

Το γρηγορότερο είναι η ίδια η Neon, **αν δεν έχουν περάσει 6 ώρες**:

1. Neon Console → το project → **Branches** → **Restore**.
2. Διάλεξε χρονική στιγμή πριν το λάθος.
3. Η Neon επαναφέρει το branch· η εφαρμογή δεν χρειάζεται αλλαγή.

Πάνω από 6 ώρες, πήγαινε στο σενάριο 2.

### 2. Παλαιότερη ζημιά — επαναφορά από αντίγραφο

Μη γράφεις πάνω στην παραγωγή. Δούλεψε σε νέο branch:

1. Neon Console → **Branches** → **New branch** (π.χ. `restore-20261003`).
2. Αντίγραψε το connection string του νέου branch.
3. Επανάφερε εκεί:
   ```powershell
   .\restore-db.ps1 -Target Custom -ConnectionString 'postgresql://…νέο branch…'
   ```
   (χωρίς `-BackupFile` παίρνει το νεότερο· αλλιώς δώσε ποιο θέλεις)
4. Έλεγξε τα δεδομένα — το script τυπώνει σύνοψη με τα πλήθη.
5. Azure Portal → App Service → **Configuration** → άλλαξε το
   `ConnectionStrings__DefaultConnection` στο νέο branch → Restart.
6. Όταν βεβαιωθείς, διάγραψε το παλιό branch.

### 3. Χάθηκε ο λογαριασμός Neon

1. Νέο project στη Neon (ή σε όποιον πάροχο PostgreSQL).
2. `.\restore-db.ps1 -Target Custom -ConnectionString '…'`
3. Ενημέρωσε το connection string στο App Service και κάνε restart.

Τα migrations εφαρμόζονται μόνα τους στην εκκίνηση, αλλά το αντίγραφο ήδη
περιέχει ολόκληρο το σχήμα — δεν χρειάζεται τίποτα άλλο.

### Δοκιμή σε τοπική βάση

```powershell
.\restore-db.ps1 -Target Local -Database RentDb_restoretest -Recreate
```

## Τι ΔΕΝ καλύπτεται

- **Τα αρχεία στο Cloudflare R2** (φωτογραφίες παγίων, δικαιολογητικά). Η βάση
  κρατά μόνο τα κλειδιά τους. Αν χαθεί το bucket, οι εγγραφές θα δείχνουν σε
  ανύπαρκτα αρχεία. Χρειάζεται ξεχωριστός συγχρονισμός (π.χ. `rclone sync`).
- **Μέρες που ο υπολογιστής είναι κλειστός.** Η εργασία τρέχει μόλις ανοίξει
  (`StartWhenAvailable`), αλλά οι ενδιάμεσες μέρες χάνονται. Για αντίγραφα
  ανεξάρτητα από το μηχάνημα χρειάζεται προγραμματισμένη εργασία στο cloud.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `init-secrets.ps1` | Αποθηκεύει connection string και κωδικό (DPAPI) |
| `backup-db.ps1` | Το καθημερινό αντίγραφο |
| `restore-db.ps1` | Επαναφορά σε στόχο που δηλώνεις |
| `verify-backup.ps1` | Μηνιαία άσκηση επαναφοράς |
| `install-task.ps1` | Προγραμματισμός (και `-Remove` για αφαίρεση) |
| `settings.ps1` | Προεπιλογές· παρακάμπτονται από `settings.local.ps1` |
| `lib/common.ps1` | Κοινές συναρτήσεις: κρυπτογράφηση, psql, διατήρηση |
